## Software

`talmolab/STRIDE` 1.0.0, MIT license. The repository carries a `CITATION.cff`; a software DOI
will be added when the release is archived.

## Models and data

STRIDE ships no trained models. The trained model weights of the original study are to be
deposited (DOI to be added). The raw T-maze videos and derived tables of the original study:
repository and DOI to be added.

## Built on

[SLEAP](https://sleap.ai) for pose estimation. The gait measures follow
[Sheppard et al. (2022)](https://doi.org/10.1016/j.celrep.2022.110231) and
[Bellardita & Kiehn (2015)](https://doi.org/10.1016/j.cub.2015.04.005).
